🍦 FrostByte — Artisanal Ice Cream Landing Page
A vibrant, pixel-perfect, responsive landing page crafted for FrostByte Ice Cream, featuring playful aesthetics, structured typography, and dynamic interactive elements.

📸 Preview

✨ Features
Pixel-Perfect Hero Layout: Multi-layered visual stack containing a responsive background disc, 5-scoop ice cream cone asset, and custom badge highlights.
Fully Responsive Design: Seamlessly adapts across mobile (<768px), tablet, and wide desktop viewports using utility-first CSS.
Pop-Out 3D Product Showcase: Interactive product cards featuring 3D overflow imagery for Ice Creams, Ice Coffee, and Milkshakes.
Split-Background Locations Section: Clean cards floating across a dual-tone backdrop (white-to-pink split) with clear branch details.
Interactive React Integration: Lightweight React component embedded via CDN for dynamic button interactions without heavy framework overhead.
Mobile Navigation Drawer: Slide-in responsive menu overlay driven by lightweight vanilla JavaScript.

🛠️ Tech Stack
Technology             Purpose
HTML5              Semantic structure & layout scaffolding
Tailwind CSS       Utility-first responsive styling & design tokens
JavaScript (ES6+)  Mobile drawer toggle & backdrop controls
React 18 & Babel   Interactive UI state handling

🚀 Getting Started
No build tools or Node.js environment required to run this project locally.

Clone the repository:
git clone https://github.com/umerfarooq0320/Scoops-Ice-Cream-landing-page.git

Navigate to the project directory:
cd frostbyte-landing-page

Launch the page:
Open index.html directly in any modern web browser, or
Use VS Code Live Server extension for real-time previewing.
